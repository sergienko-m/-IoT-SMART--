# IoT Greenhouse — практична робота 2.1

Комплект містить Arduino-скетч для ESP32 та OpenHAB-конфігурацію розумної теплиці.

## Швидкий запуск

1. Встановити Arduino IDE/PlatformIO та бібліотеки `PubSubClient`, `DHT sensor library`, `BH1750`, `OneWire`, `DallasTemperature`, `ESP32Servo`.
2. У `.ino` змінити Wi-Fi і MQTT параметри.
3. Підключити датчики й актуатори за таблицею в PDF-звіті.
4. Прошити ESP32.
5. Встановити Mosquitto та OpenHAB MQTT Binding.
6. Скопіювати файли OpenHAB у `things`, `items`, `rules`, `sitemaps`.
7. Запустити sitemap `greenhouse` і перевірити телеметрію.

## Безпека

Не підключайте насос, нагрівач або мережеві лампи без реле/MOSFET, запобіжників і гальванічної розв'язки. Облікові дані в прикладі демонстраційні; перед реальною експлуатацією замініть їх і використовуйте MQTT TLS.

## Обмеження результатів

У цьому комплекті немає фізичного стенда та реальних скріншотів/відео. Тестова таблиця у звіті — модельна перевірка сценаріїв і конфігурації; фактичну демонстрацію потрібно виконати на обладнанні.
